ASL frontend

One UI for MediaPipe letters, PyTorch image letters (CNN, MobileNet, ResNet, VGG), YOLO letters, and WLASL word recognition. Upload a still image or video for letter models (videos are sampled server-side); use live camera for WLASL or for letters — letter streams also run the Part 3 decoder (smoothed letters → words → sentence).

How to see every model: choose Backend first — the Model menu below updates. For CNN, MobileNet, ResNet, or VGG, pick PyTorch image, then open Model (four options).

Live video

Browser captures the camera locally; frames are posted to the Flask server. WLASL uses a rolling 30-frame buffer, so it needs a few seconds before the first word prediction appears. Letter backends (MediaPipe, PyTorch image, YOLO) buffer frames for the Part 3 text decoder — spell slowly with short pauses between words.
